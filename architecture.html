System Architecture

Synthetic Genomic Detector

End-to-end bioinformatics pipeline for identifying engineered genetic sequences through k-mer complexity analysis, database alignment, and machine learning classification.

1
Data Ingestion & Pre-Processing
Entry point — Raw data standardization
Input
Raw Genomic Sequences (FASTA / FASTQ)
Sequence Validation
Checks for formatting errors, verifies file structure integrity, and filters out invalid nucleotide characters (non-ATCG/N bases).
Standardization
Normalizes sequence data into a uniform format — consistent encoding, header parsing, and quality score calibration for downstream engines.
Output
Cleaned Genomic Sequence Data
2
Bioinformatics Analysis Engine
Parallel processing — Core analysis logic
Input
Cleaned Genomic Sequence Data
Track A
k-mer Complexity Analysis
Breaks the sequence into substrings of length k, calculates frequency distributions, and identifies unnatural repetitions or low-complexity regions indicative of synthetic assembly.
Track B
BLAST+ Database Alignment
Queries the sequence against established databases of natural genomes. Identifies "unmapped" regions or anomalous alignments that do not correspond to known evolutionary biology.
